A premium, fully responsive fine dining restaurant front-end website created to deliver an elegant digital culinary experience.

## ✨ Features
* **100% Fully Responsive:** Flawlessly displays across mobile devices, tablets, and desktops.
* **Luxury UI/UX:** Warm aesthetic tones, high-end typography, and smooth navigation layout.
* **Interactive Sections:** Clean navigation bar linking to Menu, Gallery, Our Story, and Table Reservations.
* **Call to Action:** Direct buttons for "Explore Menu", "Watch Experience", and "Book a Table".

---

## 🛠️ Tech Stack
* **HTML5** - Page Structure & Content
* **CSS3 / Bootstrap** - Layout, Styling & Responsive Grids
* **JavaScript** - Interactive Components
